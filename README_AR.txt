مشروع تطبيق دفتر مصروفي لنظام Android

ما يتضمنه المشروع:
- واجهة HTML مضمّنة داخل التطبيق.
- يعمل دون إنترنت؛ لا توجد صلاحية INTERNET كما تم حظر تحميل موارد الشبكة من WebView.
- JavaScript و LocalStorage و IndexedDB لحفظ البيانات والصور محلياً.
- دعم اختيار صور الإيصالات من الهاتف.
- قفل بصمة/تحقق حيوي مربوط بخدمة Android BiometricPrompt.
- إصلاح خلل تسجيل دفعات الأقساط، ومراجعة ربط حسابات الديون والتذكيرات الشهرية.

بناء APK محلياً:
1) ثبّت Android Studio وافتح مجلد DaftarMasroofyAndroid كمشروع.
2) ثبّت Android SDK Platform 35 عند الطلب.
3) انتظر انتهاء Gradle Sync (يلزم اتصال إنترنت أول مرة لتنزيل الاعتمادات).
4) اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5) ستجد الملف عادةً في app/build/outputs/apk/debug/app-debug.apk.

بناء APK عبر GitHub Actions:
1) ارفع محتويات هذا المشروع إلى مستودع GitHub جديد.
2) افتح تبويب Actions في المستودع.
3) اختر Build Android APK ثم Run workflow، أو ادفع التعديلات إلى فرع main/master.
4) بعد نجاح البناء، افتح تشغيل الـ workflow وحمّل artifact باسم daftar-masroofy-debug-apk.

ملاحظات مهمة:
- أول بناء يحتاج اتصالاً لتنزيل Gradle ومكتبة AndroidX Biometric.
- البصمة تتطلب جهاز Android يدعم وسيلة تحقق حيوي ومفعّلة عليه.
- التذكيرات داخل التطبيق فقط أثناء تشغيله؛ الإشعارات عند إغلاق التطبيق لم تُنفذ بعد.
- حذف بيانات التطبيق أو إلغاء تثبيته قد يؤدي إلى فقدان البيانات. لا توجد حالياً وظيفة تصدير/استيراد.
- المشروع اجتاز فحوصات صياغة JavaScript وXML الساكنة، لكن لم يتم بناء APK أو اختباره على هاتف في بيئة العمل الحالية.
- راجع «ملاحظات_المراجعة.txt» لمعرفة تفاصيل الإصلاحات وحدود الاختبار.
